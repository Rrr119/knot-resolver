.. _mod-recursefwd:

Recursive forwarding policy
===========================

The :ref:`policy module <mod-policy>` does not affect queries generated by the
resolver itself while following delegations, i.e. recursive sub-queries.  This
module applies forwarding policy to those sub-queries as well, so a name inside
a configured subtree is always resolved through the chosen upstream instead of
ordinary recursion.

Load the module after the iterator so its ``produce`` hook sees every
(sub-)query:

.. code-block:: lua

  modules.load('recursefwd > iterate')

Forward every query inside a subtree to one or more upstreams:

.. code-block:: lua

  recursefwd.suffix('example.com.', '192.0.2.53')
  recursefwd.suffix('example.org.', {'192.0.2.53', '2001:db8::53@5353'})

Forward every query regardless of QNAME, or remove a previously added rule:

.. code-block:: lua

  local rule = recursefwd.all('192.0.2.53')
  recursefwd.del(rule)

The module leaves the default configuration untouched and only changes queries
that match an explicit rule.  Queries already in forwarding mode are never
reconfigured, which makes it safe to combine with the policy module.
